# Egyesuletunk-tevekenysege
 Down-szindrómás gyermekek fejlesztésének és társadalmi beilleszkedésének támogatása.
 Tevékenységünk során kiemelt figyelmet fordítunk a korai fejlesztésre, a mozgás- és kognitív képességek erősítésére, valamint az egyéni szükségletekhez igazított fejlesztési programok kialakítására.
Szakembereink gyógypedagógiai, mozgásfejlesztő és szociális támogatást nyújtanak, miközben a szülőket is segítik a gyermekek mindennapi fejlődésének támogatásában. Fontosnak tartjuk a közösségi élményeket, a szocializáció fejlesztését és az inkluzív foglalkozásokat, ahol a gyermekek együtt, támogató környezetben fejlődhetnek.
